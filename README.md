# CurlingStat — Парсер и Аналитическая Платформа curling.ru (2016–2026)

Комплексная система сбора данных с официального сайта [Федерации кёрлинга России (curling.ru)](https://curling.ru/), аналитическая база данных, расчетный модуль динамических рейтингов (Elo) и продвинутой статистики по эндам, а также веб-дашборд.

---

## 🚀 Возможности системы

1. **Полный охват турниров (2016–2026 гг.)**:
   - Автоматический сбор соревнований из Архива, Календаря (события и AJAX-подгрузка) и раздела Результатов.
   - Сбор итоговых мест, полных составов команд (скипы, вице-скипы, запасные, тренеры), табло каждого матча со счетом по каждому энду, значком хаммера (🔨), экстра-эндами и ссылками на PDF-протоколы/сетки плей-офф.
2. **Разделение по дисциплинам и категориям**:
   - **Классика**: Мужские команды, Женские команды.
   - **Смешанные команды (Микст)**.
   - **Смешанные пары (Дабл-микст)**.
   - **ПОДА / Кёрлинг на колясках** (Смешанные команды и смешанные пары ПОДА).
   - **Юниоры и Юниорки** (до 22, до 19, до 17 лет).
   - **Международные турниры** и студенческая лига.
3. **Модуль аналитики и рейтингов**:
   - **Динамический рейтинг Elo**: расчет силы каждого игрока на основе результатов матчей, силы соперников и разницы очков.
   - **Рейтинг команд**: совокупный расчет силы команд на основе рейтинга игроков и истории пьедесталов.
   - **Энд-статистика**:
     - *Конверсия хаммера (Hammer Conversion %)*: процент взятия 2+ очков со своим хаммером.
     - *Процент краж (Steal %)*: процент выигранных эндов без хаммера.
     - *Удержание (Force %)*: способность сдержать соперника с хаммером до 1 очка.
     - *Сыгранные и выигранные энды, нули (Blank ends)*.
4. **Интерактивный веб-дашборд (Web SPA)**:
   - Темная тема в стиле современной спортивной аналитики.
   - Фильтры по дисциплинам, сезонам (2016–2026), сортировка по Elo, винрейту, медалям, хаммеру и кражам.
   - Кликабельные карточки соревнований с открытием интерактивного табло всех игр турнира по эндам.
   - Детальные профили игроков с историей рейтинга и турниров.
5. **Экспорт в PostgreSQL**:
   - Готовый SQL-дамп `curling_export_postgres.sql` для быстрой загрузки в любую реляционную СУБД.

## 📁 Структура проекта

```
parser/
├── api/
│   └── main.py                 # FastAPI REST API бэкенд
├── analytics/
│   ├── ratings.py              # Расчет Elo рейтингов для игроков и команд
│   └── stats.py                # Расчет энд-статистики (Hammer, Steals, Force)
├── db/
│   ├── database.py             # Схема и подключение к SQLite
│   └── export_to_postgres.py   # Экспорт базы данных в PostgreSQL SQL-дамп
├── scraper/
│   ├── crawler.py              # Сбор ссылок соревнований 2016–2026
│   ├── extractor.py            # Разбор HTML (Ход турнира, составы, итоговые места, PDF)
│   ├── runner.py               # Многопоточный сборщик с дисковым кэшированием
│   └── storage.py              # Сохранение распарсенных данных в БД
├── web/
│   ├── index.html              # Интерактивный SPA дашборд
│   ├── css/style.css           # Стили, анимации и адаптивная верстка
│   └── js/app.js               # Клиентская логика, фильтрация, модальные окна
├── curling_data.db             # Основная база данных SQLite (готов к работе)
├── curling_export_postgres.sql # PostgreSQL дамп со всей структурой и данными
├── run_server.py               # Скрипт запуска веб-сервера
└── README.md
```

## ⚡ Быстрый запуск

### 1. Запуск веб-сайта
```bash
python run_server.py
```
После запуска сайт доступен по адресу:
👉 **http://localhost:8000**

Swagger API документация:
👉 **http://localhost:8000/docs**

### 2. Запуск парсера (обновление данных)
```bash
python scraper/runner.py
```

### 3. Пересчет рейтингов и аналитики
```bash
python analytics/stats.py
```

### 4. Экспорт базы в PostgreSQL
```bash
python db/export_to_postgres.py
```
Генерирует файл `curling_export_postgres.sql`, который можно загрузить в PostgreSQL:
```bash
psql -U username -d dbname -f curling_export_postgres.sql
```
