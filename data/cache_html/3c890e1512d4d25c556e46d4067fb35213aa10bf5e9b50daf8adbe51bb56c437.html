C 1 по 3 февраля в Москве на Красной площади прошёл международный турнир по кёрлингу среди мужских команд «WCT Red Square Classic 2019».

В соревнованиях приняли участие пять команд из США, Швейцарии, Чехии, Швеции, Италии и пять российских команд.

 

По регламенту турнира команды были поделены на две группы (по пять команд в каждой), сыграли по кругу. По результатам группового этапа по две лучшие команды из групп вышли в полуфинал. Все игры состояли из 6 эндов. В случае ничьей для определения победителя игрались экстра-энд(ы). Матчи проводились без контроля отсчёта времени.

По результатам соревнований призовые места распределились следующим образом:

1 место - команда Россия 2 (скип Сергей Глухов)

2 место - команда Санкт-Петербурга (скипи Алексей Тимофеев)

3 место - команда Чехии (скип Дэвид Сик)
